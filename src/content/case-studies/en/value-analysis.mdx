_Value Analysis converts different units and pack sizes into one common "each" price so items from different vendors and manufacturers can be compared fairly._

## Problem

Hospital value-analysis committees run projects to standardize products and reduce cost. To compare offers fairly, every price has to be expressed in the same unit:

- **Unit of measure:** how an item is sold, such as a box, case or pack.
- **Each price:** the price of one single unit after converting the pack size.
- **Normalized items:** items whose units could be mapped to a common each price. Non-normalized items are the ones that could not.

## Approach & alternatives considered

The workflow follows how a committee works:

1. Cost-center analysis to find where spend is concentrated.
2. Product groups, built from nouns, types and attributes.
3. Item selection and a multi-step item analysis.
4. An impact calculator that estimates the effect of a change for the selected group.
5. Committees and project management, with Superset dashboards embedded in the workflow.

On the front end, I built the project-creation wizard (product groups, then items, then project details), the project list, detail and item views, and the committee settings. The area has its own layout and a "leave without saving" guard.

## Data design

Normalization starts from the item master. Items are grouped by manufacturer and manufacturer item ID, mapped to UNSPSC and GMDN codes, and assigned to nouns and types. Unit-of-measure mismatch fields are carried through the APIs, so the analysis can show where units don't line up.

## Failure handling

The analysis shows normalized and non-normalized items separately, so items with incomplete unit data stay visible instead of being mixed into the each-price comparison.

## Security

Access to the Value Analysis area is checked per user, with dedicated permission and error pages.

## Results

- Customers compare savings quickly: every item's price is broken down to its smallest package (each) by vendor and manufacturer.
- Hours of manual analysis saved.
- Apples-to-apples price comparison across vendors, from product group to committee review in one workflow.
