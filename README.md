# Tri Huu Nguyen — Portfolio

Bilingual (EN/VI) portfolio website for software engineer.

## Setup
1. Copy CLAUDE.md, docs/*.md into project root.
2. npm install
3. npm run dev

## Structure
- src/components/ — Reusable UI components
- src/pages/ — Routes (index, services, case-studies/[slug])
- src/content/ — MDX case studies + UI strings
- public/resume/ — PDF files
- docs/ — Specs (PRD, DESIGN, CONTENT, TASKS)
